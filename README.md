## 先分清两件事：你要的是「联机服」还是「云游戏平台」

腾讯云上叫「游戏」的产品不止一条线，买错方向会白花钱。腾讯云游戏云解决方案面向的是把游戏跑在云端、再把画面串流给玩家的场景，涉及自研 Tencent-RTC 音视频传输、JitterBuffer 管理、Pacing Rate 与编码配合降渲染延迟，以及对不同游戏调度不同级别 vGPU、在云端统一做游戏更新和版本管理。这套东西是给云游戏平台方和游戏厂商准备的。

你要的通常简单得多：一台有公网 IP 的服务器，装好服务端，朋友用 IP 连进来。这种需求用不到 vGPU 调度，也用不到 RTC 串流，一台轻量应用服务器就能解决。

腾讯云轻量应用服务器（Lighthouse）的产品定位里，适用场景明确列了「游戏服」，和网站、Web 应用、小程序/小游戏、电商应用、云盘、开发测试环境并列。它把云资源按套餐整体售卖，带宽和月流量包打包在套餐里，热门软件做成应用镜像可以一键构建。对开服的人来说，这种售卖方式比自己拼 CPU、内存、系统盘、带宽、流量要省事。

## 带宽和月流量：开服最容易算错的一笔账

对游戏服务器来说，带宽比 CPU 更容易成为瓶颈。玩家数量增加、模组包变大、地图加载频繁，都会推高服务器的上行占用。腾讯云的带宽单位是 Mbps，指的是这台机器对外的上行速率上限，不是玩家下载速度的叠加值。

按常见开服情况给几条实用判断：

- 3–10 人，原版或轻量模组，7Mbps 带宽基本够用，对应上表第三档的 2核4G
- 15–25 人，或者装了大型整合包，建议直接上 12Mbps 那档的 4核8G，省得后期迁移
- 只是办活动、临时开放给几十人进来看一眼，峰值 200Mbps 那两档更合适

月流量包也要看。200GB/月那档适合测试和极小型服务器，正常运营的联机服选 1000GB 或 2000GB 更稳。另外，那两档 200Mbps 是「峰值带宽」，官方表述对应的是突发性大带宽需求，不适合当作持续高并发的保障来理解。如果你是长期满负荷跑几十人，老老实实选固定带宽的档位。

还有一个容量问题容易被忽略。2024 年有第三方整理过腾讯云游戏联机服务器的配置档位，出现过 4核16G12M、8核32G22M、4核32G10M、16核64G35M 这样的组合，面向的是幻兽帕鲁、雾锁王国这类比较吃内存的游戏。这说明一件事：如果是帕鲁这种服务端本身就吃大内存的游戏，2核4G 不用考虑，直接从 4核16G 量级起步。那份整理是 2024 年的，具体在售配置和价格要以你下单时官网显示的为准。

## 包年包月还是按量计费

腾讯云官方定价页给了两种基本模式。按量计费按实际使用量和使用时长付费，不需要支付前期成本，支持随时购买随时释放，适合业务量不确定的阶段。包年包月是提前付费预留资源，能降低资源被占满的风险，预算也更好做，同时可以享受折扣；用得越久、量越大，单价越低。

映射到开服场景：

- 稳定长期开、朋友固定每周上线：包年包月，成本摊薄最明显
- 假期集中玩一个月、之后可能就散了：按月买，或者走按量计费
- 临时测试整合包能不能跑起来：按量计费，测完直接释放，不留残余成本

## 什么情况下不该选 Lighthouse

Lighthouse 的产品定位是面向轻量应用场景，它的优势来自套餐化和简单易用，代价是灵活性不如 CVM。以下几种情况，CVM 更合适：

- 需要挂载多块数据盘，或者对存储类型有具体要求
- 需要自定义 VPC、子网、安全组，跟其他云资源做内网互通
- 要同时跑游戏服、数据库、缓存，机器之间走内网通信
- 需要按负载做弹性伸缩，或者将来可能要迁到负载均衡后面

CVM 的定位是弹性计算服务，可以随业务需求实时扩展或缩减计算资源，用户可以按需选择实例计算能力、存储空间和网络访问方式。这些能力 Lighthouse 给不了，但反过来说，如果你只是开一个联机服，这些能力你也用不上。

## 常见问题

**开一个 10 人的 Minecraft 服务器，腾讯云要多少钱？**

**Lighthouse 和 CVM 到底差在哪？**

Lighthouse 按套餐整体售卖云资源，带宽和流量包打包在内，适合游戏服、网站、小程序后端这类轻量场景；CVM 提供完整的弹性计算能力，配置自由度高，网络和存储可自定义，适合需要组网和扩展的架构。

**买完多久能开服？**

实例创建是分钟级的。真正的时间成本在装服务端、配防火墙规则、导入地图和模组上。

**能不能先买小配置，之后升级？**

在同一产品线内可以调整配置，但跨产品线（比如从 Lighthouse 换到 CVM）通常要重新部署。开服前把人数和模组规模估准，比事后折腾便宜。
